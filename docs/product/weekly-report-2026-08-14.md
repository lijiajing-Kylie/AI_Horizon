# Horizon 周报（8.9 – 8.14）

> 本周核心：**公众号内容抓取通道升级** + **内容沉淀到知识库**，同时把报告库、论文解读和日报质量往前推了一步。整体从"能抓、能看"走向"更好用、更可沉淀"。

## 本周重点

### 1. 微信公众号抓取换新通道（本周最大工程）

公众号一直是内容源的重要一块，但旧方案依赖浏览器模拟，抓取慢、易被风控、服务器部署困难。本周把整条抓取链路迁到轻量 HTTP 通道：

- 31 个公众号 feed 完成迁移，抓取更快更稳；
- 部署到服务器不再需要浏览器环境，云端跑得更省心。

**产品意义**：微信内容的稳定供给得到保障，VPS/容器化部署成为可行的日常形态。

### 2. 新增「保存到知识库」

每条新闻详情页新增一键保存：把内容（含 AI 中文翻译正文）导出为 Markdown 文件，落进本地笔记。

**产品意义**：Horizon 第一次真正接住"看完觉得好、想留下"的诉求，优质内容可以沉淀进个人知识库，而不是看完即走。

### 3. 研究报告库更好用了

- 新增**综合分排序**：按"AI 相关度 × 篇幅分量"给报告排出质量高低，列表页可在时间/综合两种排序间切换；
- 新增 **AI 关键词**：每份报告自动提取 5-8 个关键词，快速判断相关性；
- **微信报告的正文清洗**：去掉公众号页脚噪音，正文干净可读。

**产品意义**：报告库从"能看"升级为"可挑选"——找高质量报告更快、更准。

### 4. 论文解读升级 + 金融视角

- **解读结构重构**：从原来字段繁多的解读精简为 7 个核心字段（背景+问题 / 方法 / 证据 / 影响），读起来更精炼、更有洞察；旧版解读可一键重新生成。
- **AI+金融交叉论文专属「金融视角」**：面向"懂金融、不懂 AI"的读者，每个字段先讲金融侧含义（对交易、风控、投研、定价意味着什么），再补一句 AI 说明——金融人不用先啃懂 AI 技术才能判断这篇论文值不值得读。

**产品意义**：论文库对"泛读者"更友好，金融交叉论文能直接服务金融侧用户。

### 5. 日报质量更均衡

优化摘要回填逻辑：只在内容不足、补位时才启用来源配额，避免某类来源刷屏。日报来源构成更健康。

## 下周展望

- 知识库保存功能的多条/批量形态（视反馈而定）。
